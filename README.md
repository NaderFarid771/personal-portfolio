# Personal Portfolio Website

A responsive personal portfolio website built with HTML and CSS to introduce a web developer, showcase project cards, highlight core technologies, and provide contact information.

## Features

- Sidebar profile section with navigation links
- Featured projects displayed in a responsive grid
- About section with a short introduction and technology tags
- Contact section with email, phone, and social links
- Responsive layout for desktop, tablet, and mobile screens
- Hover effects and a consistent visual style

## Technologies Used

- HTML5
- CSS3
- Font Awesome 6 for icons

## Project Structure

```text
portfolio-website/
├── index.html
├── style.css
├── Nader.png
└── README.md
```

> Make sure `Nader.png` is in the same folder as `index.html`, or update the image path in the HTML.

## How to Run Locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and the profile image in the correct locations.
3. Open `index.html` in your browser.

No build tools or installation steps are required.

## Notes

- The project uses Font Awesome from a CDN and project-card images from Unsplash, so an internet connection is needed for those external assets.
- The contact form is currently a front-end layout only; it does not send messages until connected to a backend or form service.
- Update the sample project cards, profile details, and contact links before using the site as a public portfolio.
